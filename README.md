# iQOO美化

vivo / iQOO（OriginOS 6 / 7）音量面板与系统界面美化模块，基于 LSPosed。

## 功能

### 音量面板
- 自定义背景图片、透明度、圆角、卡片效果
- 音量柱字体颜色、图标颜色

### 系统美化（设置）
- 给系统「设置」单独设置背景图
- 内容不透明度、字体颜色（8 色）

## 使用条件

| 项 | 要求 |
|---|---|
| 机型 | vivo / iQOO（OriginOS 6 或 7） |
| 权限 | 必须 root（KernelSU / Magisk） |
| 框架 | LSPosed |
| 作用域 | 系统界面、设置 |

> 小米 / 华为 / OPPO 等机型**不可用**：音量面板类名不同，hook 无法生效。

## 安装

1. 安装 APK
2. LSPosed → 模块 → 启用「iQOO美化」
3. 作用域勾选：**系统界面**、**设置**
4. 重启手机
5. 打开 App → 关于 → 复制设备码，联系作者获取卡密 → 激活
6. 外观页点「重启系统界面」，音量面板即生效

## 更新

App 内「关于 → 检查更新」即可，无需手动下载。

## 已知限制

- 设置里的「权限」子页面由系统自绘，背景无法覆盖
- 部分系统卡片在低不透明度下仍为浅白
