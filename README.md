# OriginOS 音量面板美化

基于 **LSPosed** 的模块，用来改造 vivo OriginOS 系统音量面板的外观。

**[⬇ 下载最新版](https://gitee.com/baymax1021/OriginOS-VolumePanel/raw/main/dist/)**

> 本仓库仅用于发布与更新检查，不含源码。

## 功能

| 功能 | 说明 |
|---|---|
| 自定义背景图 | 面板底色换成自己的图片 |
| 面板背景透明度 / 圆角 | 0–100% / 0–60dp |
| 音量柱透明度 | 0–100% |
| 面板字体颜色 / 图标颜色 | 8 种颜色可选 |
| 应用内更新 | 打开 App 自动检查新版本 |

## 适配

- 实测：vivo V2520A / Android 17 / OriginOS 17 / LSPosed 2.2.1
- 目标：OriginOS 6 / OriginOS 7
- 非 vivo 设备无效；系统面板改版后需适配

## 安装

1. 需要持久 root（Magisk / KernelSU）+ LSPosed
2. 安装 APK，LSPosed 中启用模块，作用域勾选「系统界面」
3. 打开 App 完成激活 → 配置 → 重启系统界面
